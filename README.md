# Automatic Question Generation System

A Streamlit-based application that automatically generates questions from text, PDF files, or topics using NLP and Transformer models.

## Features
- Generate questions from text input
- Generate questions from PDF documents
- Topic-based question generation using Wikipedia
- Uses Transformer-based NLP model

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- NLP
- T5 Transformer Model

## Installation

Clone the repository:

git clone https://github.com/lakshmibhargavikota/Automatic-Question-Generation-System.git

Install dependencies:

pip install -r libraries.txt

Run the application:

streamlit run app.py

## Model Used
valhalla/t5-base-qg-hl
